# BizwitAI Showreel — brief
Goal: in 30 s, show that BizwitAI builds the AI (automation, agents, data) that runs a modern business.
Audience: Indian founders, SMB owners, agency teams.   Platform: bizwitai.com hero / showreel section.
Format: 1920×1080, 30 fps, 30 s (900 frames), 16:9.
Style: ClimbX-reference structure (black emblem open → full-bleed accent slide → soft white UI scenes →
dark glowing chart slide → huge numerals → pill CTA), rendered "AI-driven + embossed" like bizwitai.com:
soft neumorphic cards (double inner/outer shadows), glossy embossed emblem, neural-line/particle accents.
Brand (from bizwitai.com, user-supplied): bg #000000 · panels #04070D / #0D0F17 · text #FFFFFF · muted #D5DBE6 ·
accent #0080FF (glow orb, buttons, full-bleed slide) · accent2 #009DFF · accent3 #814AC8 (subtle glows only).
Fonts: Figtree 500–800 headings/body, Instrument Serif italic for emphasis words, JetBrains Mono labels.
UI scenes use dark embossed panels (#0D0F17 with top highlight + deep shadow) to match the site, instead of the reference's soft white.
Audio: built-in synth SFX + ambient pad, whoosh/impact on cuts, ticks on counters. No narration.
CTA: "book a call" pill + bizwitai.com
Copy rules (brand voice): no em dashes; no "leverage / delve / synergy / streamline / game-changer".
Must stay exact: BizwitAI, bizwitai.com. No invented stats: only "24/7" and "5+ industries"
(real estate, e-commerce, HR, sales, marketing) are used as numbers; UI values in mock cards are illustrative.
